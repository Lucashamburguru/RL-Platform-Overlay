## 2023-10-27 - Optimized JSON parsing and platform string evaluation
**Learning:** In hot path parsing like network update loops, methods like `serde_json::Value`'s array indexing (e.g., `value["Key"]`) create overhead by returning static `Value::Null` references on misses, which often causes downstream evaluation steps to repeat dictionary lookups. Additionally, string manipulation methods like `.to_lowercase()` trigger heap allocations, which cause measurable churn when parsing thousands of high-frequency events.
**Action:** Replaced repetitive `.as_X()` lookups on `value["Key"]` with single `.get("Key")?` unwraps to safely handle missing keys and shortcut execution. For string evaluations, swapped `to_lowercase()` with `eq_ignore_ascii_case()` and switched `split('|').collect::<Vec<_>>()` to iterator chaining (`.next()`) to bypass intermediate array collections.
